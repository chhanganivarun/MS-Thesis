\section{MPC Implementation}

We have provided the implementation of Model Predictive Control Algorithm. 

The implementation of MPC algorithm has the following components:

\begin{itemize}
    \item System Model
    \item Cost function
    \item Prediction Horizon
    \item Optimization problem solver
\end{itemize}
