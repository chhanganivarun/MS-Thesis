This thesis addressed Vision-and-Language Navigation for autonomous driving in dynamic outdoor environments. We argued that existing approaches---graph-based indoor VLN, discrete-action outdoor VLN, and single-image navigable-region grounding---are insufficient when the referred goal is not yet visible, when fine manoeuvres are required, and when navigation must be evaluated live in a changing scene.

We introduced CARLA-NAV, a meta-dataset of language-guided outdoor navigation episodes in the CARLA simulator, with dense annotations for intermediate and final navigable regions and short-term future trajectories. The observer--navigator--verifier protocol, combined with automated projection of clicked regions into segmentation masks, enabled scalable curation across multiple maps and weather conditions.

We then argued formally for a grounding-first factorisation---dense navigable-region prediction plus a fixed local planner---and proposed a multi-task network that predicts navigable-region and future-trajectory masks from multi-frame CLIP features, a historical contextual trajectory, and the language command. Predicted masks are used for live navigation with an empirical area-based stopping rule (five consecutive predictions above a threshold whose numeric value was not recorded). On the 25/34-episode validation/test splits, CLIP-MC reaches human-evaluated Task Completion of $0.72$ / $0.68$ (Wilson 95\% CIs $[0.52,0.86]$ / $[0.51,0.81]$), outperforming single-frame CLIP and RNR baselines on aggregate metrics, with corresponding improvements in Fr\'{e}chet Distance and nDTW. Preliminary ViT and Conv3D (X3D) models, evaluated with Fr\'{e}chet/FDE/ADE/ADE-Match and stratified by command type, action, target, and subcommand count, document the earlier architectural lineage and quantify path-metric dispersion. We document the limits of these gains (sample size, human TC labelling, shared-map splits, missing safety metrics) and specify an extended evaluation protocol for follow-up.

Overall, grounding-then-navigating provides an interpretable and continuous-control alternative to discrete VLN formulations, and is a promising direction for language-conditioned autonomous driving.

\section{Ethics and Safety}

This work studies language-conditioned control in simulation only. We do not claim that the system is safe for real vehicles: collision, lane-invasion, and traffic-light metrics are specified in Chapter~\ref{ch:vln} but were not part of the original evaluation; synthetic-to-real appearance and traffic gaps remain large; and referential commands can be ambiguous. Any path toward deployment would require independent safety monitors, human override, and evaluation under adversarial and long-tail scenarios beyond CARLA-NAV.

\section{Future Work}

\begin{itemize}
    \item \textbf{Map-unseen and multi-seed evaluation:} Execute the held-out-map protocol and multi-seed live runs with Wilson/bootstrap intervals described in Chapter~\ref{ch:vln}.
    \item \textbf{Safety metrics:} Log CARLA collisions, lane invasions, and red-light infractions alongside Task Completion.
    \item \textbf{Trajectory-head ablation and runtime:} Quantify whether the auxiliary trajectory head improves navigation, and profile inference latency versus frame count $T$.
    \item \textbf{CLIP per-manoeuvre TC:} Extend the ViT/Conv3D stratified tables to Task Completion for the CLIP family.
    \item \textbf{Real-world transfer:} Domain adaptation techniques~\cite{kundu2021generalize,kang2020pixel} are needed before deployment on real vehicles.
    \item \textbf{Learnable stopping:} Replacing the rule-based area threshold with a learned stopping policy~\cite{xiang-etal-2020-learning} should improve robustness.
    \item \textbf{Trajectory-conditioned control:} The predicted future trajectory is currently used for interpretability; incorporating it into the planner could improve end-to-end behaviour.
    \item \textbf{Richer evaluation:} Developing metrics that respect multiple valid paths for the same command would better reflect outdoor driving ambiguity.
    \item \textbf{Interactive language:} Extending the setting to clarification dialogues and multi-turn instructions would bring the system closer to human co-driving.
\end{itemize}
